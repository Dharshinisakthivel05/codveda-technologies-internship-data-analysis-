Codveda Technologies — Data Analytics Internship

About the Internship

This repository contains my project work completed during the Data Analytics Internship at Codveda Technologies. The internship provided hands-on practice in data preprocessing, exploratory data analysis, statistical analysis, regression, time series analysis, data visualization, dashboard development, and sentiment analysis.

Tools & Technologies

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Jupyter Notebook / Google Colab
- Power BI
- CSV datasets

Tasks Completed

Level 1 — Data Analysis Fundamentals

- Task 1: Data Cleaning and Preprocessing — Cleaned and checked a customer churn dataset for missing values and duplicate records.
- Task 2: Exploratory Data Analysis (EDA) — Explored stock price data using descriptive statistics, distributions, box plots, scatter plots, and correlation analysis.

Level 2 — Advanced Data Analysis

- Task 1: Regression Analysis — Built a linear regression model to examine the relationship between stock opening and closing prices.
- Task 2: Time Series Analysis — Analyzed stock closing prices over time and explored price changes and moving averages.

Level 3 — Advanced Analytics Projects

- Task 1: Power BI Dashboard — Developed a customer churn analysis dashboard to explore churn distribution and customer service-related patterns.
- Task 2: NLP Sentiment Analysis — Analyzed text sentiment and explored sentiment distribution across platforms using Python.
